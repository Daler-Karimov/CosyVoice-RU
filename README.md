# CosyVoice-RU: Локальное клонирование голоса (Voice Cloning) на русском языке

[![Python 3.10+](https://img.shields.io/badge/Python-3.10%2B-blue.svg)](https://www.python.org/)
[![PyTorch](https://img.shields.io/badge/PyTorch-2.4%2B%20%7C%20CUDA-orange.svg)](https://pytorch.org/)
[![Gradio](https://img.shields.io/badge/UI-Gradio-orange.svg)](https://gradio.app/)
[![License: Apache 2.0](https://img.shields.io/badge/License-Apache%202.0-green.svg)](LICENSE)

Готовая сборка современной нейросети **CosyVoice 3.0 (Fun-CosyVoice3-0.5B-2512)** для высококачественного локального клонирования любого голоса с полной поддержкой **русского языка**, встроенным **Whisper** для автоопределения текста образца и удобным **WebUI на Gradio**.

---

## Особенности и отличия от базового CosyVoice

1. **Чёткий и разборчивый русский язык без галлюцинаций:**
   * Устранена критическая проблема несовместимости с библиотеками `transformers >= 4.53`, из-за которой в оригинальной модели нарушался механизм KV-кэширования Qwen2 и на выходе получались случайные галлюцинации и бессвязные звуки.
   * Настроены точные версии зависимостей и корректные токены промптов для идеального синтеза русской речи.

2. **Встроенное автораспознавание образца речи (Whisper):**
   * Вам больше не нужно вручную вбивать точный текст произнесённых слов из образца голоса.
   * Локальная модель **Whisper (base)** автоматически за доли секунды транскрибирует ваш образец, обеспечивая максимальное совпадение интонации и тембра.

3. **Адаптация под Windows:**
   * Исправлены ошибки бэкенда `torchaudio` с отсутствующими DLL и кодировками консоли Windows (UTF-8 / CP1251).
   * Запуск и установка производятся в один клик через `.bat` скрипты.

4. **Аппаратное ускорение на современных GPU:**
   * Протестировано и оптимизировано для видеокарт NVIDIA (включая серии RTX 5080 / 4090 / 4080 / 3090) с CUDA 12.8+.
   * Реальное время синтеза (RTF) около 0.75 — 5 секунд чистой речи генерируются всего за ~3.8 сек.

## Быстрый старт (Windows)

### Способ 1: В один клик через bat-скрипты

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/Daler-Karimov/CosyVoice-RU.git
   cd CosyVoice-RU
   ```
2. Запустите установщик **`install.bat`**:
   * Создастся виртуальное окружение `.venv`
   * Установятся все необходимые библиотеки (PyTorch с CUDA, Gradio, Whisper, CosyVoice)
   * Автоматически загрузятся веса модели `Fun-CosyVoice3-0.5B-2512`
3. Запустите веб-интерфейс через **`run_ui.bat`**:
   * Откроется браузер по адресу `http://127.0.0.1:7865`

---

### Способ 2: Ручная установка (Windows / Linux)

```bash
# 1. Клонирование
git clone https://github.com/Daler-Karimov/CosyVoice-RU.git
cd CosyVoice-RU

# 2. Создание и активация виртуального окружения
python -m venv .venv

# Windows:
.venv\Scripts\activate
# Linux:
source .venv/bin/activate

# 3. Установка зависимостей
pip install --upgrade pip
pip install -r requirements.txt

# 4. Скачивание весов модели CosyVoice 3.0
python download_cosyvoice.py

# 5. Запуск веб-интерфейса
python webui.py
```

## Рекомендации для наилучшего клонирования голоса

* **Длина образца:** Рекомендуется от **5 до 12 секунд** связной, уверенной речи.
* **Качество записи:** Без посторонних шумов, громкой музыки на фоне и сильного эха комнаты.
* **Интонация:** Модель копирует манеру речи, эмоции и тембр из вашего образца.
* **Поддерживаемые языки:** Русский, Английский, Китайский, Японский, Корейский, Французский, Немецкий, Испанский, Итальянский.

```text

├── webui.py                 # Главное приложение с веб-интерфейсом Gradio и Whisper
├── download_cosyvoice.py    # Скрипт автоматической загрузки весов (HuggingFace + зеркало ModelScope)

├── requirements.txt         # Проверенные стабильные зависимости
├── .gitignore               # Исключение моделей и кэша
├── CosyVoice_repo/          # Модули CosyVoice 3.0 и Matcha-TTS с патчами под Windows
└── README.md                # Документация проекта
```
